# Knowledge Gap Finder

> AI that audits your knowledge base and finds missing, stale or conflicting articles.

Analyzes tickets, chats and docs to surface knowledge gaps, then drafts new articles for review.

**Live:** https://ziontechgroup.com/knowledge-gap-finder/  
**Network hub:** https://github.com/Zion-support/zion-app-network

## Features
- Ticket-driven gap detection with clustering
- Staleness and conflict scoring for existing articles
- Auto-drafted articles via [zion-ai-knowledge-base](https://github.com/Zion-support/zion-ai-knowledge-base)
- Deflection analytics showing gaps closed
